# Pilot Observation Checklist

Pilot sırasında gözlemlenecek operational noktalar.

## Kasiyer Akışı

- [ ] Kasiyer SAYI + ENTER akışında takılıyor mu?
- [ ] Sipariş numarası yanlış giriliyor mu? (harf, boşluk, vs.)
- [ ] Kasiyer HAZIR butonuna zamanında basıyor mu?
- [ ] TESLİM EDİLDİ unutuluyor mu? (listede şişme)
- [ ] GERİ AL kullanımı oluyor mu? Ne sıklıkla?
- [ ] Kasiyer ekranı kapatıyor mu?

## Müşteri Akışı

- [ ] Müşteriler QR akışını anlayabiliyor mu?
- [ ] QR okutulduktan sonra ne yapacaklarını biliyorlar mı?
- [ ] "Siparişiniz Hazır" mesajı görünüyor mu?
- [ ] Müşteriler ekranı açık bırakıyor mu?
- [ ] Bildirim geliyor mu?

## Display

- [ ] Display çalışıyor mu? (TV/tablet)
- [ ] Gerçek zamanlı güncelleme görünüyor mu?
- [ ] Sipariş hazır olduğunda display'e yansıyor mu?
- [ ] Teslim edildiğinde display'den kalkıyor mu?

## Genel

- [ ] Uygulama yavaşlıyor mu?
- [ ] Hata mesajları çıkıyor mu?
- [ ] Çevrimdışı durum oluyor mu?
- [ ] Session düşüyor mu? (tekrar login gerekiyor mu?)

## Kayıt

Her gözlemi `docs/PILOT-ISSUES.md` dosyasına kaydedin.
Gün sonunda kısa özet yazın.
